# Deployment Checklist

Quick pre-flight list. Full instructions in [DEPLOYMENT.md](DEPLOYMENT.md).

## Before pushing

- [ ] `npx hardhat test` passes (only needed if `contracts/` changed)
- [ ] Frontend builds clean: `npm run build`
- [ ] No secrets committed — `.env`, `frontend/.env`, `backend/.env` are all gitignored
- [ ] New frontend origins added to `allowedOrigins` in [backend/server.js](backend/server.js)

## Environment variables

**Railway (backend)**
- [ ] `NODE_ENV=production`
- [ ] `MONGO_URI` — Atlas connection string
- [ ] `ADMIN_WALLET` — valid `0x` + 40 hex chars, or the server won't boot
- [ ] `FRONTEND_URL=https://critcoin.art`
- [ ] `CLOUDINARY_CLOUD_NAME` / `CLOUDINARY_API_KEY` / `CLOUDINARY_API_SECRET`

**Vercel (frontend)**
- [ ] `REACT_APP_API_URL` — Railway backend URL
- [ ] `REACT_APP_ADMIN_WALLET`
- [ ] `CI=false`

> `REACT_APP_*` values are baked in at build time. Changing one requires a rebuild.

## Deploy

Push to `main` — Railway and Vercel both auto-deploy. Watch both dashboards for green.

## After deploy

- [ ] `curl https://critcoin-platform-production.up.railway.app/health` returns `mongodb: Connected`
- [ ] https://critcoin.art loads over HTTPS
- [ ] MetaMask connects and shows a Sepolia CritCoin balance
- [ ] Profile creation with a photo works (exercises Cloudinary)
- [ ] Project submission and an on-chain tip both succeed
- [ ] Forum post + comment + vote work
- [ ] Prediction page loads and respects the open/closed setting
- [ ] Admin panel opens from the admin wallet and is hidden from student wallets
- [ ] Archive page lists past semesters

## If the contract was redeployed

- [ ] `frontend/src/contracts/` files regenerated by `scripts/deploy.js`
- [ ] `backend/sepolia.json` **manually** updated — the script doesn't write it
- [ ] Contract address updated in README.md, HANDOFF.md, and DEPLOYMENT.md
- [ ] Frontend rebuilt so the new address ships
- [ ] Students told their old balances live on the previous contract
