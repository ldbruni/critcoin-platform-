# CritCoin Frontend

React SPA for the CritCoin platform. Built with `create-react-app` (react-scripts 5), React Router 6, Bootstrap 4, and **ethers.js v5**.

See the root [README.md](../README.md) for setup and [HANDOFF.md](../HANDOFF.md) for architecture.

## Running

```bash
npm start          # plain HTTP on :3000
npm run start-dev  # HTTPS, bound to 0.0.0.0 — matches the root start-dev
```

Prefer `npm run start-dev` from the repo root, which starts the backend alongside it.

Requires `frontend/.env`:
```env
REACT_APP_API_URL=http://localhost:3001
REACT_APP_ADMIN_WALLET=0xYourAdminWalletAddress
```

`REACT_APP_*` values are read at build/start time only — restart after editing.

## Conventions

**API base URLs** are built inline per page:
```js
const API = {
  profiles: process.env.REACT_APP_API_URL
    ? `${process.env.REACT_APP_API_URL}/api/profiles`
    : "http://localhost:3001/api/profiles"
};
```
There's no shared API client — follow the existing pattern when adding a page.

**Chain access** is ethers **v5**: `new ethers.providers.Web3Provider(window.ethereum)`. Contract address and ABI come from `src/contracts/sepolia.json`. Do not use v6 syntax.

**Admin gating** in `App.js` compares the connected wallet to `REACT_APP_ADMIN_WALLET` and only hides the nav link. It is cosmetic — every admin action is enforced server-side by signature.

## Building

```bash
npm run build              # standard CRA build
npm run build-production   # NODE_ENV=production
```

Production deploys run `build-for-vercel.sh` from the repo root, not these directly.
